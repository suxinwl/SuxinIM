## 数据和业务约定

业务表显式使用 `biz_*` / `wecom_*`，独立连接禁用宿主自动表前缀。访问核心身份表继续使用宿主前缀。可选外部标识为 NULL，不会因多个手工员工的空工号触发唯一键冲突。外部打卡和审批按来源加引用标识幂等写入。

时间统一 Asia/Shanghai。时长字段单位为小时；月统计按排班工作区间与已批准申请区间求交集、去重并剔除休息时间。重叠时段按请假、外出、出差优先分配，避免重复统计。尚未结束的班次不统计缺卡、迟到和旷工。没有排班不会推断默认工作日，跨夜班次归入开始日期。异常数按班次、缺卡数按上下班边界、工作天数按自然排班日期统计；这不是工资结算规则。

手工 API 不能覆盖同步来源的考勤记录。企业微信审批撤销、驳回、删除取消对应有效业务记录；未配置模板或控件无法解释的记录只保留原始数据和异常，不猜测时间字段。

企业微信按任务类型使用令牌缓存与限流；一次运行只允许一个同步任务，网络调用在插件工作进程后台执行。失败保留游标，成功历史回补不倒退游标。重启后把遗留 running 批次标为失败，下一次任务可重试。
